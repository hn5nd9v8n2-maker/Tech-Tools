# TECH TOOLS — Central do Técnico

Plataforma web em um único arquivo HTML, criada por Técnico Carlos Ivan.

## Ferramentas incluídas
1. Localizador de CTOs (base incorporada do arquivo original Localizador_CTO-1.html).
2. Calculadora de Compatibilidade Óptica.
3. Medição de postes (estimativa por quantidade/distância média e soma de vãos reais).
4. Guia Wi-Fi.
5. Checklist de instalação.

As opções Calculadora de Splitter e Reincidência 30D não fazem parte desta versão.

## Publicar no GitHub Pages
1. Extraia os arquivos do ZIP.
2. Envie `index.html` para a raiz do repositório GitHub.
3. Em Settings → Pages, selecione a branch desejada e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

## Observações
- A busca de CTOs funciona localmente no navegador e abre coordenadas no Google Maps.
- O portal não depende de servidor ou banco de dados.
- As ferramentas ópticas e de postes são auxiliares; valide medições e critérios com o projeto e padrões da operação.
